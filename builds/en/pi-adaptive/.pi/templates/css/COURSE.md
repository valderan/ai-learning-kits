# Course: CSS — responsive layout

## Learning goal

Build responsive layouts confidently with flexbox and grid, with custom properties and careful typography, enough to turn a Figma mockup into a landing page.

## Student context

- Current level: knows HTML, has copied CSS from examples
- Why learning: pet project and first layout jobs
- Time and pace: 3 hours per week
- Format: practice in this project, the mockup at hand
- Practice: self-study

## What you will be able to do

- understand the cascade and specificity instead of fighting them
- lay out sections with flexbox and grid
- build responsive versions for mobile, tablet and desktop
- keep styles in custom properties without duplicating rules

## Out of scope

- preprocessors, Tailwind, JS-driven animation

## When a topic counts as done

- the mockup is laid out and looks correct at three widths
- the student has explained why they chose flexbox or grid

## Program

### Module 1. Basics

1. Linking styles, selectors, the cascade
2. Specificity, inheritance, `!important`
3. Colors, units, `rem` and `em`

### Module 2. Box model and flow

4. Box model: margin, border, padding, `box-sizing`
5. `display`: block, inline, inline-block
6. Positioning and `z-index`

### Module 3. Flexbox

7. The axis and `display: flex`
8. Alignment and distribution
9. Typical layouts: header, cards, footer

### Module 4. Grid

10. Columns, rows, `fr`
11. Areas and `grid-template-areas`
12. Grid or flexbox: when to use which

### Module 5. Responsiveness

13. Media queries and mobile-first
14. Flexible images and units
15. Container queries

### Module 6. Presentation

16. Typography and web fonts
17. CSS custom properties
18. Transitions, transforms, animations
