# Course: Python — FastAPI backend

## Learning goal

Write small Python services with tests; the vector is a REST API on FastAPI, enough to build a pet project and show it at an interview.

## Student context

- Current level: basic syntax, has written scripts
- Why learning: pet project and interview
- Time and pace: 5 hours per week
- Format: practice in this project, reading other people's solutions
- Practice: self-study

## What you will be able to do

- work confidently with types, collections and comprehensions
- design code from classes, dataclasses and modules
- write tests with pytest and keep the code clean with ruff
- stand up a REST API on FastAPI with validation via pydantic

## Out of scope

- ML/LLMs, Django, deployment and queues

## When a topic counts as done

- the assignment works, `pytest` passes
- the student has explained the solution in their own words

## Program

### Module 1. Language basics

1. Variables, types, f-strings
2. Conditionals, loops, range
3. Functions, arguments, scopes
4. Working with strings

### Module 2. Collections

5. Lists, tuples, slices
6. Dictionaries and sets
7. Comprehensions and generators

### Module 3. OOP and modules

8. Classes, methods, dunder methods
9. dataclasses
10. Modules, packages, venv and uv

### Module 4. Errors and data

11. Exceptions and handling them
12. Files, paths, context managers
13. JSON and working with external data

### Module 5. Tests and quality

14. pytest: fixtures and parametrization
15. Type hints and mypy, the ruff linter

### Module 6. Practice: FastAPI

16. A FastAPI application, routes, dependencies
17. Pydantic models and validation
18. Testing the API with TestClient
