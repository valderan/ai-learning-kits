# Курс: Go — от основ до HTTP-сервиса

## Цель обучения

Писать идиоматичный Go: консольные утилиты и небольшой HTTP-сервис с тестами, чтобы пройти собеседование на junior Go-разработчика.

## Контекст студента

- Уровень сейчас: уверенный Python, Go не писал
- Зачем учит: собеседование
- Время и темп: 4–5 часов в неделю
- Формат: практика в этом проекте, теория — по ходу
- Практика: самостоятельно

## Что будет уметь в конце

- писать код в идиомах Go: ошибки как значения, интерфейсы, пакеты
- работать с горутинами и каналами, не ловить гонки данных
- покрывать код табличными тестами и запускать `go test -race`
- поднимать HTTP-сервис с JSON API

## Что в курс не входит

- gRPC, Kubernetes, инфраструктура и деплой

## Как считается, что тема закрыта

- задание работает, `go test ./...` проходит
- студент объяснил решение своими словами

## Программа

### Модуль 1. Основы языка

1. Переменные, типы, константы
2. Условия, циклы, switch
3. Функции и множественные возвраты
4. Ошибки как значения

### Модуль 2. Данные и структуры

5. Массивы, срезы, мапы
6. Структуры и методы
7. Указатели и получатели

### Модуль 3. Организация кода

8. Интерфейсы
9. Пакеты и модули (`go mod`)
10. Стандартная библиотека: `fmt`, `strings`, `errors`, `time`

### Модуль 4. Конкурентность

11. Горутины
12. Каналы и select
13. `sync`, `context`, отмена

### Модуль 5. Тесты и инструменты

14. `go test` и табличные тесты
15. Бенчмарки, `go vet`, `golangci-lint`

### Модуль 6. Практика: HTTP-сервис

16. `net/http`: роутинг и handlers
17. JSON и ошибки API
18. Тесты HTTP-обработчиков
