# Учебный режим — инструкция студенту

Этот набор превращает агента в наставника: он подсказывает, проверяет и объясняет, но код пишешь ты. Режим **включён всегда**, пока в корне проекта лежит `AGENTS.md` с этими инструкциями — отдельно включать ничего не нужно.

## Как устроен набор

| Что | Где | Зачем |
|---|---|---|
| Персона наставника | `AGENTS.md` в корне проекта | Основная сессия агента читает этот файл при старте — поэтому режим работает с первого сообщения |
| Скиллы | `.agents/skills/<id>/SKILL.md` | Шесть скиллов, которые агент подхватывает по ситуации |
| Шаблоны курса | `.agents/templates/<язык>/` | Примеры `COURSE.md` и `COURSE_PROGRESS.md` для Go, Python, TypeScript и CSS |
| Эта инструкция | `.agents/README.md` | Для тебя, агент её не читает |

## Быстрый старт

1. Скопируй в корень учебного проекта `AGENTS.md` и папку `.agents`.
2. Если в проекте уже был свой `AGENTS.md` — не перезаписывай его, а допиши инструкции наставника в конец.
3. Запусти агента в этом проекте — режим уже действует.

Особые случаи:

- **Claude Code**: если в проекте есть `CLAUDE.md`, он перекрывает `AGENTS.md` — допиши инструкции наставника в `CLAUDE.md` (или удали его, если он не нужен). Скиллы Claude Code берёт из `.claude/skills`, поэтому добавь ссылку: `mkdir -p .claude && ln -s ../.agents/skills .claude/skills`.
- Другие агенты, которые не читают `AGENTS.md`, — посмотри в README их файл инструкций и скопируй туда содержимое `AGENTS.md`.
- Некоторые агенты (например, pi) при первом запуске спрашивают разрешение на проектные файлы — ответь «да», иначе скиллы не загрузятся.

## Программа курса и прогресс

В корне проекта могут лежать два необязательных файла:

```
COURSE.md           # что и зачем учим: цель, контекст, модули и темы, материалы
COURSE_PROGRESS.md  # строка «Сейчас: N. Тема» и чек-лист пройденного
```

Агент читает их в начале сессии и дальше ведёт подсказки в рамках текущей темы, не забегая вперёд. Если файлов нет — он один раз предложит их создать и не будет настаивать.

Три способа завести файлы курса:

1. **Дать программу агенту.** Скажи: «вот моя программа обучения» и пришли её текстом, файлом или ссылкой. Агент разберёт её, проверит актуальность по официальным источникам (если есть доступ к веб-поиску), покажет черновик и создаст файлы.
2. **Попросить курс с нуля.** Скажи: «хочу научиться NestJS». Агент сначала спросит про твой уровень, цель и время, затем предложит 2–3 вектора обучения — и после твоего выбора создаст файлы.
3. **Взять готовый пример.** Скопируй `.agents/templates/<язык>/COURSE.md` и `COURSE_PROGRESS.md` в корень проекта и замени темы на свои.

Как устроен прогресс:

```markdown
Сейчас: 2. Функции

- [x] 1. Переменные и типы
- [ ] 2. Функции
- [ ] 3. map и filter
```

- Текущая тема — из строки `Сейчас`, а если её нет — первый пункт без `[x]`.
- Тему закрывает агент, но **только по твоей прямой просьбе**: «закрой тему», «отметь, что я прошёл». Он поставит `[x]` и перенесёт `Сейчас` на следующий пункт.
- Программу можно обновить в любой момент: «обнови программу», «проверь актуальность». Агент предложит правки; уже пройденные темы останутся нетронутыми.

### Конспекты и задачи

- `notes/<NN>.md` — конспекты по темам: агент создаёт по просьбе «объясни тему» или «сделай конспект».
- `tasks/<NN>.md` — задачи для самоподготовки: 3–5 штук от простого к сложному, только на текущую и уже пройденные темы.
- Агент не предлагает конспекты и задачи сам — только по твоей просьбе. Если в `COURSE.md` стоит «Практика: задачи от наставника», задачи по курсу ты делаешь с наставником, а дополнительные агент сделает только после уточнения.

## Скиллы

В агентах с поддержкой скиллов они подключаются сами по описанию ситуации. Если умеешь вызывать вручную — попробуй `/skill:<id>`.

| Скилл | Когда срабатывает |
|---|---|
| `hint-ladder` | «застрял», «не получается», «не знаю, как дальше» — подсказки по ступеням, от направления до готового решения |
| `code-review` | «проверь мой код», «что не так с решением» — разбор без переписывания |
| `debug-coach` | ошибка, стектрейс, «падает», «выдаёт не то» — разбор ошибки без готового фикса |
| `explain-code` | «объясни этот код», «что тут происходит» — разбор по блокам или построчно |
| `course-plan` | программа курса: разобрать программу, составить курс, обновить её, закрыть тему |
| `topic-lesson` | «объясни тему», «сделай конспект», «дай вопросы на проверку», «дай задачи на закрепление» — конспект в `notes/`, задачи в `tasks/` |

Если агент не подхватил скилл сам — скажи прямо: «прочитай `.agents/skills/hint-ladder/SKILL.md` и действуй по нему».

## Подтверждения действий

Набор не настраивает права: у каждого агента свой механизм подтверждений, и это нормально. Если подтверждения включены — соглашайся или отклоняй действия агента, но не проси его обходить защиту. Если хочется жёсткого контроля, посмотри README набора: там собраны рецепты для pi, Claude Code, Codex и OpenCode.

Главное правило «код пишешь ты» в любом случае держит сама персона наставника, а не настройки прав.

## Проверка, что режим работает

- Напиши «я застрял» — агент должен выдать «Подсказка 1 из 4» без готового кода.
- Напиши «проверь мой код» — получишь ревью со ссылками вида `файл:строка`, без переписанного решения.
- В начале сессии в проекте с `COURSE.md` в транскрипте должны быть видны чтения `COURSE.md` и `COURSE_PROGRESS.md` — до первого ответа.

## Если что-то не так

| Симптом | Что делать |
|---|---|
| Агент ведёт себя как обычный ассистент | Проверь, что `AGENTS.md` в корне проекта и агент его читает (у Claude Code — что нет мешающего `CLAUDE.md`) |
| Агент не сослался на программу | Напиши «прочитай COURSE.md и COURSE_PROGRESS.md» |
| Прогресс не отмечается без просьбы | Так и задумано: скажи «закрой тему» |
| Скиллы не находятся | Скажи «прочитай `.agents/skills/<id>/SKILL.md`»; в pi проверь подтверждение доверия проекту |
| Хочу обычный режим работы | Переименуй или удали `AGENTS.md` (верни на место, когда снова понадобится) |

## Полное выключение режима

- На время: переименуй `AGENTS.md` в `AGENTS.md.off` — персона исчезнет, скиллы останутся доступны.
- Навсегда: удали `AGENTS.md` и папку `.agents` из проекта.
