# all-adaptive — учебный режим для любого агента

Учебный режим для общих стандартов агентов: **AGENTS.md** для инструкций основной сессии и **`.agents/skills/`** для скиллов. Наставник подсказывает, проверяет и объясняет, но **код пишет студент**.

Отличие от [pi-adaptive](../pi-adaptive/README.md): здесь нет ничего привязанного к конкретному харнессу — ни `.pi`, ни `pi-guard`, ни доверия проекту. Только два переносимых артефакта: `AGENTS.md` и папка `.agents`.

## Состав

```
all-adaptive/
├── README.md                # этот файл
├── AGENTS.md                # персона наставника → копируется в корень проекта
└── .agents/
    ├── README.md            # подробная инструкция студенту
    ├── skills/              # 6 скиллов (Agent Skills spec)
    │   ├── hint-ladder/     # подсказки по ступеням
    │   ├── code-review/     # ревью решения
    │   ├── debug-coach/     # разбор ошибки
    │   ├── explain-code/    # объяснение кода
    │   ├── course-plan/     # работа с программой курса и прогрессом
    │   └── topic-lesson/    # тема: конспект, вопросы, задачи
    └── templates/           # примеры COURSE.md + COURSE_PROGRESS.md
        ├── go/  python/  typescript/  css/
```

## Установка

```bash
cp builds/ru/all-adaptive/AGENTS.md /путь/к/учебному/проекту/
cp -R builds/ru/all-adaptive/.agents /путь/к/учебному/проекту/
```

Если в проекте **уже есть** `AGENTS.md` — не перезаписывай его, а допиши набор в конец:

```bash
printf '\n\n' >> /путь/к/проекту/AGENTS.md
cat builds/ru/all-adaptive/AGENTS.md >> /путь/к/проекту/AGENTS.md
```

Дальше просто запусти агента в проекте — режим действует с первого сообщения.

## Совместимость

| Агент | Читает `AGENTS.md` | Читает `.agents/skills/` |
|---|---|---|
| OpenAI Codex | да | да (родная директория) |
| Cursor | да | да |
| Gemini CLI | да | да (приоритетнее `.gemini/skills`) |
| VS Code / Copilot | да | да (наряду с `.github/skills`, `.claude/skills`) |
| OpenCode | да | да |
| pi | да | да (нужно подтвердить доверие проекту) |
| Windsurf, Kiro, Antigravity и др. | да | да |
| **Claude Code** | ⚠️ только если в проекте нет `CLAUDE.md` (с версии 2.1.277) | ❌ — читает только `.claude/skills` |

Особенности Claude Code:

- если `CLAUDE.md` уже есть, он перекрывает `AGENTS.md` — допиши персона в `CLAUDE.md`;
- скиллы подключи ссылкой:
  ```bash
  mkdir -p .claude && ln -s ../.agents/skills .claude/skills
  ```

Примечание для pi: `.agents/templates/*.md` не мешают `pi-subagents` — файлы без frontmatter `name`/`description` там молча пропускаются.

## Зависимости

Нет. Ни расширений, ни плагинов, ни настроек: только markdown-файлы.

## Подтверждения действий (опционально)

Единого стандарта прав между агентами нет, поэтому набор не настраивает их сам. Поведенческие правила («не правь файлы без явной просьбы», «не обходи подтверждения») уже лежат в `AGENTS.md`. Если нужен жёсткий контроль, включи штатный механизм своего агента:

- **pi** — расширение `pi-guard`: правила можно положить в `.pi/settings.json` (из проектного файла читаются только правила, а `enabled` — глобальная настройка в `~/.pi/agent/settings.json`): правки и запись — `ask`, тесты и чтение — `allow`; включение — `/guard enable`. Готовый пример — в `builds/ru/pi-adaptive/.pi/settings.json`.
- **Claude Code** — `permissions` в `.claude/settings.json` (правила вида `Bash(npm test:*)`, `Edit`); синтаксис — в доке вашей версии.
- **Codex** — `approval_policy` и `sandbox_mode` в конфиге (`~/.codex/config.toml`).
- **OpenCode** — блок `permission` в описании агента: пример есть в сборке [`opencode-adaptive`](../opencode-adaptive/v1/.opencode/agents/student.md).
- **Cursor, Copilot, Gemini CLI** — штатные подтверждения инструментов, включаются в настройках.

## Проверка

1. Скопировать `AGENTS.md` и `.agents` в тестовый проект, запустить агента.
2. Написать «я застрял» → ответ «Подсказка 1 из 4», без готового кода.
3. В проекте с `COURSE.md` — в начале сессии видны чтения `COURSE.md` и `COURSE_PROGRESS.md`.
4. Сказать «хочу научиться <технология>» → агент задаёт уточняющие вопросы и предлагает 2–3 вектора курса, а не сразу пишет файлы.

## Ограничения

- `AGENTS.md` — не system prompt, а контекст проекта: его вес и приоритет зависят от агента, но в большинстве харнессов он читается при старте.
- Скиллы без поддержки в харнессе всё равно работают: персона просит прочитать `.agents/skills/<id>/SKILL.md`.
- Чтение `COURSE.md` — действие модели по инструкции, а не хук.
- С Claude Code есть ручные шаги (см. «Особенности Claude Code»), автоматизировать их набор не пытается.
