# Учебный режим для OpenCode 1.x — инструкция студенту

Эта папка превращает OpenCode в наставника: агент подсказывает, проверяет и объясняет, но код пишешь ты. Режим **включён сразу**: агент `student` прописан основным в проекте, отдельно выбирать его не нужно.

## Что внутри

| Файл | Зачем |
|---|---|
| `opencode.json` | Проектный конфиг: `"default_agent": "student"` — агент становится основным при запуске |
| `agents/student.md` | Персона наставника и права: правки — с подтверждением, тесты и программа курса — без |
| `skills/` | Шесть скиллов, которые агент подхватывает по ситуации |
| `templates/` | Примеры `COURSE.md` и `COURSE_PROGRESS.md` для Go, Python, TypeScript и CSS |
| `README.md` | Этот файл |

## Быстрый старт

1. Скопируй папку `.opencode` в корень учебного проекта.
2. Запусти `opencode` в этом проекте — агент `student` уже основной.
3. Посмотреть список агентов и переключиться можно по Tab/Shift+Tab, но для учёбы ничего переключать не нужно.

## Программа курса и прогресс

В корне проекта могут лежать два необязательных файла:

```
COURSE.md           # что и зачем учим: цель, контекст, модули и темы, материалы
COURSE_PROGRESS.md  # строка «Сейчас: N. Тема» и чек-лист пройденного
```

Агент читает их в начале сессии и дальше ведёт подсказки в рамках текущей темы, не забегая вперёд. Если файлов нет — он один раз предложит их создать и не будет настаивать.

Три способа завести файлы курса:

1. **Дать программу агенту.** Скажи: «вот моя программа обучения» и пришли её текстом, файлом или ссылкой. Агент разберёт её, проверит актуальность по официальным источникам (если есть доступ к веб-поиску), покажет черновик и создаст файлы.
2. **Попросить курс с нуля.** Скажи: «хочу научиться NestJS». Агент сначала спросит про твой уровень, цель и время, затем предложит 2–3 вектора обучения — и после твоего выбора создаст файлы.
3. **Взять готовый пример.** Скопируй `.opencode/templates/<язык>/COURSE.md` и `COURSE_PROGRESS.md` в корень проекта и замени темы на свои.

Как устроен прогресс:

```markdown
Сейчас: 2. Функции

- [x] 1. Переменные и типы
- [ ] 2. Функции
- [ ] 3. map и filter
```

- Текущая тема — из строки `Сейчас`, а если её нет — первый пункт без `[x]`.
- Тему закрывает агент, но **только по твоей прямой просьбе**: «закрой тему», «отметь, что я прошёл». Он поставит `[x]` и перенесёт `Сейчас` на следующий пункт.
- Программу можно обновить в любой момент: «обнови программу», «проверь актуальность». Агент предложит правки; уже пройденные темы останутся нетронутыми.

### Конспекты и задачи

- `notes/<NN>.md` — конспекты по темам: агент создаёт по просьбе «объясни тему» или «сделай конспект».
- `tasks/<NN>.md` — задачи для самоподготовки: 3–5 штук от простого к сложному, только на текущую и уже пройденные темы.
- Агент не предлагает конспекты и задачи сам — только по твоей просьбе. Если в `COURSE.md` стоит «Практика: задачи от наставника», задачи по курсу ты делаешь с наставником, а дополнительные агент сделает только после уточнения.

## Скиллы

Агент подхватывает их сам по описанию ситуации. Вручную можно вызвать командой `/skill:<id>`.

| Скилл | Когда срабатывает |
|---|---|
| `hint-ladder` | «застрял», «не получается», «не знаю, как дальше» — подсказки по ступеням, от направления до готового решения |
| `code-review` | «проверь мой код», «что не так с решением» — разбор без переписывания |
| `debug-coach` | ошибка, стектрейс, «падает», «выдаёт не то» — разбор ошибки без готового фикса |
| `explain-code` | «объясни этот код», «что тут происходит» — разбор по блокам или построчно |
| `course-plan` | программа курса: разобрать программу, составить курс, обновить её, закрыть тему |
| `topic-lesson` | «объясни тему», «сделай конспект», «дай вопросы на проверку», «дай задачи на закрепление» — конспект в `notes/`, задачи в `tasks/` |

## Подтверждения действий

Права прописаны в `agents/student.md`:

- чтение проекта — свободно;
- правки и запись файлов — с подтверждением;
- запуск тестов и программы курса (`npm test`, `node`, `python`, `pytest`, `go test`, `cargo test` и т. д.) — без подтверждения;
- остальные команды и незнакомые скиллы — с подтверждением.

Не проси агента обходить подтверждения. Хочешь изменить правила — отредактируй блок `permission` в `agents/student.md`.

## Проверка, что режим работает

- Напиши «я застрял» — агент должен выдать «Подсказка 1 из 4» без готового кода.
- Напиши «проверь мой код» — получишь ревью со ссылками вида `файл:строка`, без переписанного решения.
- Проверь окружение командами: `opencode debug config` (должен быть `default_agent: student`), `opencode debug agent student`, `opencode debug skill` (в списке шесть скиллов набора).
- В начале сессии в проекте с `COURSE.md` в транскрипте должны быть видны чтения `COURSE.md` и `COURSE_PROGRESS.md` — до первого ответа.

## Если что-то не так

| Симптом | Что делать |
|---|---|
| Агент ведёт себя как обычный ассистент | Проверь `opencode debug config`: если `default_agent` не `student`, значит проектный `.opencode` не подхватился — запусти opencode из корня проекта |
| Агент не сослался на программу | Напиши «прочитай COURSE.md и COURSE_PROGRESS.md» |
| Прогресс не отмечается без просьбы | Так и задумано: скажи «закрой тему» |
| Скиллы не находятся | Проверь `opencode debug skill`; убедись, что папка `.opencode/skills` целиком скопирована |
| Хочу обычный режим работы | Убери `"default_agent": "student"` из `opencode.json` — агент останется доступен через Tab/Shift+Tab |

## Полное выключение режима

- Убрать `"default_agent": "student"` из `.opencode/opencode.json` — режим перестанет быть основным, агент останется в списке.
- Переименовать или удалить `.opencode/agents/student.md` — агент исчезнет.
- Удалить папку `.opencode` из проекта — выключить всё.
