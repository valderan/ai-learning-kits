# Курс: TypeScript — типы и backend

## Цель обучения

Писать типобезопасный TypeScript: утилиты и HTTP API на Node, с тестами; вектор — backend-разработка для работы в продуктовой команде.

## Контекст студента

- Уровень сейчас: уверенный JavaScript, TypeScript не писал
- Зачем учит: работа
- Время и темп: 4 часа в неделю
- Формат: практика в этом проекте, строгий режим компилятора с первой темы
- Практика: самостоятельно

## Что будет уметь в конце

- описывать данные через типы, интерфейсы и дженерики
- безопасно работать с async/await и ошибками
- писать тесты на vitest и держать проект в strict-режиме
- принимать и валидировать данные API на границе приложения

## Что в курс не входит

- фронтенд-фреймворки, базы данных, деплой

## Как считается, что тема закрыта

- задание работает, `npm test` проходит, `tsc --noEmit` без ошибок
- студент объяснил решение своими словами

## Программа

### Модуль 1. Основы типов

1. Примитивы, вывод типов, аннотации
2. Union, literal, narrowing
3. Функции: параметры, перегрузки, this

### Модуль 2. Объекты и обобщения

4. Объектные типы, интерфейсы и type
5. Дженерики и ограничения
6. Utility-типы: Partial, Pick, Record

### Модуль 3. Классы и модули

7. Классы, модификаторы доступа, implements
8. ES-модули и настройка strict в tsconfig

### Модуль 4. Асинхронность

9. Promise, async/await
10. Обработка ошибок и типы неизвестного
11. Параллельные запросы и отмена

### Модуль 5. Тесты и инструменты

12. vitest: тесты, моки, покрытие
13. ESLint, форматирование, сборка tsc

### Модуль 6. Практика: HTTP API

14. Роутинг и обработчики на Node
15. Валидация данных через zod
16. Типизация ответов и тесты API
