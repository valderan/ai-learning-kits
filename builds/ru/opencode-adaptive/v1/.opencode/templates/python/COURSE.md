# Курс: Python — backend на FastAPI

## Цель обучения

Писать небольшие сервисы на Python с тестами; вектор — REST API на FastAPI, чтобы сделать пет-проект и показать его на собеседовании.

## Контекст студента

- Уровень сейчас: базовый синтаксис, писал скрипты
- Зачем учит: пет-проект и собеседование
- Время и темп: 5 часов в неделю
- Формат: практика в этом проекте, разбор чужих решений
- Практика: самостоятельно

## Что будет уметь в конце

- уверенно работать с типами, коллекциями и comprehensions
- проектировать код из классов, dataclasses и модулей
- писать тесты на pytest и держать код в чистоте через ruff
- поднять REST API на FastAPI с валидацией через pydantic

## Что в курс не входит

- ML/LLM, Django, деплой и очереди

## Как считается, что тема закрыта

- задание работает, `pytest` проходит
- студент объяснил решение своими словами

## Программа

### Модуль 1. Основы языка

1. Переменные, типы, f-строки
2. Условия, циклы, range
3. Функции, аргументы, области видимости
4. Работа со строками

### Модуль 2. Коллекции

5. Списки, кортежи, срезы
6. Словари и множества
7. Comprehensions и генераторы

### Модуль 3. ООП и модули

8. Классы, методы, dunder-методы
9. dataclasses
10. Модули, пакеты, venv и uv

### Модуль 4. Ошибки и данные

11. Исключения и их обработка
12. Файлы, пути, контекстные менеджеры
13. JSON и работа с внешними данными

### Модуль 5. Тесты и качество

14. pytest: фикстуры и параметризация
15. Типизация и mypy, линтер ruff

### Модуль 6. Практика: FastAPI

16. Приложение FastAPI, роуты, зависимости
17. Модели pydantic и валидация
18. Тесты API через TestClient
